## 五、大文件检查

- [ ] 普通 Git 文件中不存在超过 **50 MiB** 的待上传文件。
- [ ] 大数据库、模型、压缩包和原始文档没有混入选择范围。

只读扫描工作区大文件：

```powershell
Get-ChildItem -Recurse -Force -File |
  Where-Object {
    $_.FullName -notlike '*\.git\*' -and
    $_.Length -ge 50MB
  } |
  Sort-Object Length -Descending |
  Select-Object @{N='SizeMiB';E={[math]::Round($_.Length/1MB,1)}}, FullName
```

该扫描会列出本地保留的大模型和研究数据；它们可以继续留在本地，但不能进入首次上传文件集。

```powershell
$candidateFiles = @(
  git -c safe.directory=G:/bim-web ls-files
) | Where-Object { Test-Path -LiteralPath $_ -PathType Leaf }

rg -l -i --no-messages -- `
  'BEGIN (RSA |OPENSSH |EC )?PRIVATE KEY|api[_-]?key\s*[:=]|secret[_-]?key\s*[:=]|password\s*[:=]|Bearer [A-Za-z0-9._-]{16,}' `
  @candidateFiles
```

命中只表示需要人工复核，不代表一定包含真实秘密。不要把匹配行或秘密值复制到聊天、Issue 或提交说明。
