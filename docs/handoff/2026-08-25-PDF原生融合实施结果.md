## 运行配置

Web 服务启用该调试路径时，需要设置：

- `VECTOR_TRAINING_ROOT`：包含 `training.predict_vector` 的训练代码根目录
- `VECTOR_PYTHON`：该训练环境的 Python 可执行文件
- `VECTOR_MODEL_PATH`：可用的 `best.pt`
- `VECTOR_DEVICE=cpu`：本机无 GPU 时使用 CPU
- `VECTOR_TIMEOUT_SECONDS`：可选，默认 600 秒
- `POPPLER_PATH`：Windows 上 PDF 渲染工具目录（系统无法自动发现时设置）

不需要在本机重新训练，也不需要为了启用此阶段重新标注。`best.pt` 只负责提供概率证据。

## 当前限制与下一步

- 当前只处理水平和垂直结构线；斜墙未进入闭合拓扑。
- 当前结果没有完成真实工程尺度校准，因此仍是 `uncalibrated`/调试状态。
- 小缺口只在保守阈值内闭合，弱模型支持的闭合面会标为可疑房间。
- 下一步需要选择 5–10 份有代表性的真实矢量 PDF，检查调试叠加图和 JSON 理由，统计误接、漏接、尺寸线误判与房间闭合效果，再决定阈值是否可以固化及何时接入能耗几何。
