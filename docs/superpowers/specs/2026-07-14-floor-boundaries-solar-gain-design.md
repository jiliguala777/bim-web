# 单层负荷计算边界与太阳得热参数设计

日期：2026-07-14
状态：待用户审阅

## 1. 背景

当前网站按单层图纸逐层识别和计算。对于中间层、底层和顶层，屋面及地面传热边界并不相同，但精确计算目前始终计入屋面和地面；已有的地面接触修正系数也只进入了请求参数，没有真正参与传热计算。另外，年度太阳得热使用固定数值 150，却没有明确其物理含义、时间尺度和单位。

本次修改先完善现有年度能耗计算的输入边界和公式说明，不引入设计日峰值冷、热负荷模块。

## 2. 目标

1. 在精确计算模式中，屋面传热和地面传热默认均不启用。
2. 用户上传顶层图纸时可勾选计入屋面传热；上传底层图纸时可勾选计入地面传热。
3. 地面接触修正系数真正参与精确模式的地面传热计算。
4. 将年度太阳得热的固定常数改为含义和单位明确、可修改的参数，并在结果中回显采用值。
5. 在图纸上传区域明确提示 PDF 当前只处理单页，用户需逐页上传。
6. 保持简单计算模式现有行为，避免本次修改改变原有结果。

## 3. 不在本次范围内

- 不新增设计冷负荷或设计热负荷峰值模块。
- 不实现多层建筑的一次性上传、楼层识别和自动汇总。
- 不实现 PDF 多页选择、自动拆页或拒绝多页文件。
- 不修改 AI 图纸识别、轮廓换算或第二次识别流程。
- 不增加逐房间人数、新风、照明、设备和室内设计温度设置。
- 不接入逐时气象文件、太阳辐射数据库或逐时太阳位置算法。
- 不改变当前太阳得热对采暖能耗的简化抵扣关系。

## 4. 页面设计

### 4.1 精确模式边界开关

精确计算区域增加两个复选框：

- `计入屋面传热`：默认不勾选。
- `计入地面传热`：默认不勾选。

两个开关只在精确模式中生效。对应参数在精确模式下未勾选时禁用，在勾选后启用：

- 屋面：现有屋面传热系数。
- 地面：现有地面传热系数、地面接触类型和地面接触修正系数。

本轮不新增独立的屋面面积和地面面积字段。两项面积继续沿用“单层建筑面积”，与当前后端的数据组织保持一致。简单模式中现有屋面、地面参数继续可编辑，且计算行为不变。

页面辅助说明：

- 顶层计算时勾选“计入屋面传热”。
- 底层计算时勾选“计入地面传热”。
- 中间层通常两项均不勾选。
- 如果某层同时与室外屋面和地面接触，可同时启用。

### 4.2 年度太阳辐射参数

精确模式增加数值输入：

- 名称：`年度等效太阳辐射量`
- 默认值：`150`
- 单位：`kWh/(m²·a)`
- 最小值：`0`

该参数表示在当前简化年度模型中，单位窗面积在一年内用于估算太阳得热的等效累计太阳辐射量。它不是瞬时太阳辐照度，也不是设计日峰值负荷参数。

### 4.3 PDF 上传提示

图纸上传区域增加固定提示：

> PDF 目前仅处理单页，请先拆分或截取需要计算的楼层后逐页上传。

本次仅增加提示，不对多页 PDF 做自动检测或处理。

## 5. 前后端数据契约

精确计算请求新增以下字段：

| 字段 | 类型 | 默认值 | 含义 |
| --- | --- | --- | --- |
| `include_roof` | boolean | `false` | 是否计入屋面传热 |
| `include_floor` | boolean | `false` | 是否计入地面传热 |
| `annual_solar_irradiation_kwh_m2a` | number | `150` | 年度等效太阳辐射量，单位 kWh/(m²·a) |

已有字段 `floor_contact_factor` 保留，默认值为 `1.0`，并在本次修改后实际参与精确计算。

后端参数组织约定：

- `include_roof`、`include_floor` 放入 `geometry`。
- `floor_contact_factor`、`annual_solar_irradiation_kwh_m2a` 放入 `envelope`。
- 缺少新增字段时使用上述默认值，确保旧请求仍可处理。
- 页面发送 JSON 布尔值，不使用字符串 `"true"` 或 `"false"`。

## 6. 计算规则

### 6.1 屋面传热

精确模式屋面传热系数项为：

```text
UA_roof = include_roof ? U_roof × A_roof : 0
```

其中：

- `UA_roof`：屋面传热系数项，W/K；
- `U_roof`：屋面传热系数，W/(m²·K)；
- `A_roof`：屋面面积，m²；本轮取单层建筑面积。

### 6.2 地面传热

精确模式地面传热系数项为：

```text
UA_floor = include_floor ? U_floor × A_floor × F_contact : 0
```

其中：

- `UA_floor`：地面传热系数项，W/K；
- `U_floor`：地面传热系数，W/(m²·K)；
- `A_floor`：地面面积，m²；本轮取单层建筑面积；
- `F_contact`：地面接触修正系数，无量纲。

地面接触修正系数用于近似反映地面与土壤、非空调地下空间等不同边界条件对传热量的影响。它只修正地面传热项，不修正外墙、窗、门或屋面。

### 6.3 年度太阳得热

每个朝向的年度太阳得热按下式估算：

```text
Q_solar,orientation = A_window
                    × SHGC
                    × F_shading
                    × H_solar,annual
                    × F_orientation
                    × F_cooling
```

总年度太阳得热为各朝向之和：

```text
Q_solar,annual = Σ Q_solar,orientation
```

其中：

- `Q_solar,annual`：年度太阳得热，kWh/a；
- `A_window`：对应朝向窗面积，m²；
- `SHGC`：太阳得热系数，无量纲；
- `F_shading`：遮阳修正系数，无量纲；
- `H_solar,annual`：年度等效太阳辐射量，kWh/(m²·a)；
- `F_orientation`：朝向修正系数，无量纲；
- `F_cooling = CDD / max(CDD + HDD, 1)`：当前年度模型中用于分配到制冷期的简化比例，无量纲。

量纲关系为：

```text
m² × 1 × 1 × kWh/(m²·a) × 1 × 1 = kWh/a
```

该项的作用是补充窗户传导热以外的太阳辐射得热。太阳辐射穿过玻璃后会增加室内制冷需求，因此计入年度制冷能耗；现有模型对采暖能耗保留简化的太阳得热抵扣。本次只把时间尺度和单位显式化，不把它升级为逐时或峰值模型。

默认值仍为 150 kWh/(m²·a)，因此在其他输入不变时，默认计算结果与当前固定常数的数值保持一致。

## 7. 结果回显与可追溯性

精确模式结果应回显以下采用值：

- 是否计入屋面传热；
- 是否计入地面传热；
- 屋面 `UA`；
- 修正后的地面 `UA`；
- 地面接触修正系数；
- 年度等效太阳辐射量及单位；
- 年度太阳得热量。

这些字段进入结果的 `inputs_used` 或 `detailed_loads`，便于用户判断某层的计算边界是否正确，并能复核公式。

## 8. 默认值与异常输入

- 新增边界开关缺失时均视为 `false`。
- 年度等效太阳辐射量缺失时使用 `150`。
- 地面接触修正系数缺失时使用 `1.0`。
- 年度等效太阳辐射量和地面接触修正系数不得为负数；页面通过 `min=0` 限制，后端将负数按 `0` 处理，避免产生方向相反的非物理传热量。
- 开关已启用但对应面积为 0 时，该项贡献为 0，不中断计算。
- 简单模式不读取新增开关，保持现有公式和返回结构兼容。

## 9. 测试设计

### 9.1 计算单元测试

在 `tests/test_energy_calc.py` 增加以下测试：

1. 精确模式未提供新字段时，屋面和地面 `UA` 均为 0。
2. 启用屋面后，`UA_roof = U_roof × A_roof`。
3. 启用地面后，`UA_floor = U_floor × A_floor × F_contact`。
4. 负的地面接触修正系数按 0 处理。
5. 使用已知窗面积、SHGC、遮阳系数、朝向系数、CDD/HDD 和年度太阳辐射量时，年度太阳得热与公式一致。
6. 负的年度太阳辐射量按 0 处理。
7. 简单模式在相同旧输入下的结果保持不变。

### 9.2 页面测试

在 `tests/test_energy_template.py` 增加以下检查：

1. 屋面和地面复选框存在且默认未选中。
2. 年度等效太阳辐射量默认值为 150，并显示单位。
3. 页面包含 PDF 单页逐页上传提示。
4. 前端请求发送布尔值和年度太阳辐射参数。

### 9.3 手工冒烟验证

在运行页面中验证三种楼层：

- 中间层：屋面、地面均不勾选。
- 顶层：只勾选屋面。
- 底层：只勾选地面并修改地面接触修正系数。

确认结果回显与勾选状态一致，且启用单项后能耗变化方向合理。

## 10. 验收标准

1. 精确模式首次打开时，屋面和地面传热均不计入。
2. 用户可分别启用屋面和地面，两项互不影响。
3. 地面接触修正系数能按公式线性改变地面 `UA`。
4. 年度太阳得热输入、公式、时间尺度和单位在页面或结果中可见。
5. 默认太阳辐射参数不改变现有固定常数对应的结果。
6. PDF 上传区明确说明逐页上传的临时工作方式。
7. 现有简单模式测试继续通过。
