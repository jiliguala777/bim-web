# 保守墙体拓扑修补设计

## 目标与范围

本功能只作用于能够提取线条颜色和几何信息的矢量 PDF，并接在现有灰色辅助层清理、建筑主体 ROI 和模型识别之后。目标是在不制造错误房间的前提下，自动修补唯一且可信的单线缺口，并避免内部孤立线干扰房间面积计算。

扫描 PDF、照片和普通图片暂不使用本规则。现有模型识别结果在后台保存为诊断文件，所有自动修补生成最终计算结果。页面只展示最终计算结果，不向用户同时展示两套掩膜。

## 后台原始结果与页面最终结果

- `raw_model_mask`：模型原始识别到的墙、门和窗，仅作为后台诊断文件保存，不在页面展示。
- `calculation_mask`：从原始掩膜派生，允许忽略低可信孤立线，并最多加入通过验证的单条补线。页面识别叠加图、房间闭合、多边形、面积和后续负荷计算统一使用这份结果。
- API 同时记录新增线、忽略线、自动修补状态和拒绝原因，便于后续排查与人工编辑。

## 外轮廓单线闭合

1. 在建筑 ROI 边缘带内提取主要结构墙体的开放端点，外围标注线不得仅因位置靠外就被当作建筑外墙。
2. 只生成水平或垂直的单条直线候选。候选两端必须属于主要结构、方向相向、间距在保守上限内。
3. 候选路径应得到原始 PDF 黑色矢量几何或相邻墙体连续性的支持，不得穿过已有墙体、门窗或已确认房间。
4. 对每个候选在临时掩膜上进行模拟，检查是否把建筑内部与外部稳定分离，并形成面积、长宽比和位置合理的主体多边形。
5. 只有恰好一个候选通过全部检查时才采用。存在多个候选、需要多于一条线、补线后仍泄漏或产生异常小/狭长房间时，均不自动补线，状态设为 `manual_exterior_wall_required`。
6. 每次识别最多自动添加一条外围补线。

### 底部多门入口特例

- 普通缺口仍使用保守短距离上限；不得为了入口整体放大通用闭合核。
- 在建筑 ROI 下部识别水平矢量边界密集行，并寻找位于同一行两侧、具有足够纵向连续性的已识别竖墙锚点。
- 多扇门、门洞和短墙共线时，可从最左与最右可信锚点之间生成一条较长的水平候选线。它在拓扑上统一视为不透过的房间边界，门未分类成功时按墙处理。
- 候选线必须获得至少 80% 的逐列深色矢量支持，跨度不得超过建筑 ROI 宽度的 80%，并且模拟后新增一个合理闭合区域且不破坏已有房间。
- 同一入口附近的相邻像素行合并为一个逻辑候选。只有一个逻辑入口候选通过时才采用；两个不同高度或位置的入口候选同时通过时仍回退人工补线。

## 内部孤立线处理

1. 内部线段只有在不参与任何已闭合房间边界、与主要结构连接较弱且矢量结构支持不足时，才成为“计算忽略”候选。
2. 忽略候选先在临时计算掩膜中移除，并验证现有可信房间不会合并、消失或出现面积突变。
3. 若孤立线只需一条短的水平或垂直补线即可形成合理房间，则先模拟补线；只有唯一候选通过房间面积、长宽比、交叉和结构支持检查时才采用。
4. 无法可靠补线、也无法安全忽略的线保留在最终计算掩膜中，同时不进行自动修改并记录为 `ambiguous_internal_fragment`。
5. 内部补线按房间候选独立判断，每个候选最多增加一条线；不得借助连续多段线拼接成房间。

## 判断顺序

1. 使用现有矢量清理后的模型结果建立后台原始掩膜。
2. 在建筑 ROI 内建立墙体连通图和当前闭合房间基线。
3. 先处理唯一可信的外轮廓单线缺口，得到建筑内部有效范围。
4. 再分析有效范围内的孤立线，分别模拟“忽略”和“补一条线”。
5. 选择不会破坏已有可信房间且证据唯一的操作，生成计算掩膜。
6. 从计算掩膜提取房间多边形并生成页面叠加图；后台诊断信息单独记录自动补线和忽略线。

## 安全回退

- 没有唯一候选时不补线。
- 需要斜线、折线或多条线时不补线。
- 缺少建筑 ROI、矢量几何支持不足或模拟结果不稳定时，保持现有结果。
- 自动操作不得减少已有可信房间数量，不得把两个大房间异常合并，也不得制造低于最小面积或极端狭长的房间。
- 不能自动闭合不代表识别失败；结果应明确提示需要手动补一条外墙或检查内部边界。

## 输出信息

房间拓扑结果增加：

- 后台 `raw_model_mask` 和页面使用的 `calculation_mask` 对应结果文件；
- `exterior_repair.status`、候选数量、新增线坐标和拒绝原因；
- `internal_fragments.ignored`、`repaired`、`ambiguous`；
- `manual_exterior_wall_required` 和 `manual_review_reasons`；
- 修补前后房间数量及面积变化摘要。

## 验证标准

- 第 13 页外轮廓只有唯一可信的水平或垂直缺口时，最多补一条墙线；否则提示手动补线。
- 外围尺寸标注线不能因为“最外侧必须闭合”而被连接成房间。
- 中央大空间中的低可信孤立误识别线不再出现在页面最终结果中，也不再切割或制造房间；原始结果仅在后台诊断文件中保留。
- 一根真实内墙在通过单线补全即可形成合理房间时不会被直接忽略，而是优先进入补线模拟。
- 现有矢量 PDF、扫描 PDF、图片、多页选择和比例尺流程不回归。
