# 矢量 PDF 自动比例尺标定与房间面积设计

## 目标

以 CAD 导出的矢量 PDF 为主要输入，自动识别建筑外围的水平总尺寸和垂直总尺寸，得到可信的米/像素比例尺，并用闭合房间多边形计算房间面积。扫描 PDF 和照片不在本轮自动识别范围内，但保留人工两点标定兜底。

## 基本原则

- 尺寸识别与墙、门、窗语义分割分开处理。
- 不把“PDF 中最长的线”直接当作尺寸线，必须同时匹配尺寸数字、主尺寸线和两端界线。
- 高置信度结果自动使用；低置信度结果不得静默进入负荷计算。
- 未确认比例尺时只显示像素面积，不使用默认 `0.05 m/px`，也不使用整张图片面积估算。

## 数据流程

1. 上传 PDF 后判断页面是否包含足够的矢量文字与绘图路径。
2. 使用矢量文字和路径生成：
   - 原始页面渲染图；
   - 尺寸标注候选；
   - 标注遮罩；
   - 去标注后的几何识别图。
3. 从墙线密集区域估计建筑主体包围框。
4. 在主体上、下、左、右外围寻找总尺寸标注。
5. 分别选择覆盖主体范围最大的水平、垂直总尺寸候选。
6. 由两个方向计算比例尺并交叉校验。
7. 用标注遮罩排除尺寸线、界线和数字后，再运行墙门窗识别及房间闭合。
8. 使用确认后的比例尺换算每个房间多边形面积。

## 总尺寸候选识别

尺寸候选由以下元素共同组成：

- 可解析为正数的文字，例如 `40600`、`18600`；
- 与文字邻近、方向一致的水平或垂直主尺寸线；
- 主尺寸线两端的垂直界线、短划线或箭头；
- 位于建筑主体外围且与主体边界大致平行；
- 覆盖范围与建筑主体长或宽相符。

以下文字默认排除：

- 图纸比例，如 `1:100`；
- 面积，如 `68.80m²`；
- 标高，如 `13.500`；
- 轴号、门窗编号和包含字母的编号；
- 表格、标题栏中的数字。

同一总尺寸可能在建筑两侧重复出现。顶部与底部 `40600`、左侧与右侧 `18600` 应作为相互加强的证据，而不是重复房间边界。

## 比例尺计算与置信度

水平和垂直候选分别计算：

```text
scale_x = horizontal_actual_length_m / horizontal_span_px
scale_y = vertical_actual_length_m / vertical_span_px
axis_difference = abs(scale_x - scale_y) / mean(scale_x, scale_y)
```

- 横纵均识别且差异不超过 2%：自动确认，采用中位数。
- 差异为 2%～5%：标记为需要用户确认。
- 差异超过 5%：判定自动标定失败，不进入负荷计算。
- 只识别到一个方向：保存候选值，但要求用户确认。
- 两个方向均未识别：转入人工两点标定。

重复的顶部、底部、左侧、右侧候选以及局部尺寸链，可以提高置信度并排除异常值。

## 人工两点标定兜底

用户在原始 PDF 渲染图上选择两个端点，输入实际长度和单位。系统保存端点、像素距离、实际长度、比例尺和标定来源。人工标定可以覆盖自动候选，但不修改原始识别证据。

## 房间面积

房间面积只允许来自闭合房间多边形：

```text
room_area_m2 = room_area_px2 * scale_m_per_px²
```

识别结果保存每个房间的多边形、像素面积、平方米面积和面积来源。没有闭合房间或没有确认比例尺时，`load_geometry_ready` 必须为 `false`，禁止进入负荷计算。

## 错误处理

- 非矢量 PDF：返回 `manual_required`，不伪造自动比例尺。
- 数字与尺寸线无法可靠匹配：保存候选证据，要求人工标定。
- 横纵比例尺冲突：明确显示冲突数值和来源。
- 新文件上传或识别结果变化：旧比例尺及面积结果失效。

## 测试要求

- 从合成矢量 PDF 中识别水平、垂直总尺寸。
- 排除图框、轴网、标高、面积和 `1:100`。
- 验证顶部/底部及左侧/右侧重复尺寸的一致性。
- 验证 2% 和 5% 置信度边界。
- 验证单方向尺寸和无尺寸时的人工兜底状态。
- 验证标注遮罩不会进入房间边界。
- 验证房间面积只在闭合房间和确认比例尺同时存在时生成。
- 保证现有 PNG/JPG 识别及历史 `recognition.json` 兼容。
