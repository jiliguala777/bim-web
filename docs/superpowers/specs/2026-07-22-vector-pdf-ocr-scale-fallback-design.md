# 矢量 PDF OCR 比例尺后备与手动标定画布修复设计

日期：2026-07-22

## 目标

在不削弱现有尺寸线几何校验的前提下，让文字已转为矢量轮廓的 PDF 也能自动识别总尺寸并确认比例尺；同时修复手动两点标定首次点击后整张图片变黄、无法继续选择第二点的问题。

## 已确认根因

- 测试 PDF 第 13 页包含大量线和曲线，但 `pdfplumber` 提取结果为 `0 chars / 0 words`。尺寸数字是矢量轮廓，不是 PDF 文本对象，现有自动比例尺没有任何文字候选。
- 识别结果区域初始隐藏。原图在隐藏状态下触发 `load` 时，标定画布内部尺寸被设置为 `1×1`；首次绘制黄色标记后，这个像素被 CSS 拉伸覆盖整张图。

## 自动比例尺设计

### 处理顺序

1. 保留现有 `pdfplumber` 原生文字提取为第一优先级。
2. 仅当页面存在矢量几何、但没有可用的原生尺寸文字时，启用本地 OCR 后备。
3. OCR 只负责提供带位置的数字候选，不单独决定比例尺。
4. 将 OCR 数字候选转换到 PDF 页面坐标，复用现有尺寸线、端点标记、方向和位置校验。
5. 分别选择可信的水平、竖直总尺寸；两轴比例差不超过现有阈值时才自动确认。
6. OCR 无候选、只有单轴候选或双轴冲突时，继续返回未确认状态，不猜测比例尺。

### OCR 范围与性能

- OCR 全程在本机执行，不调用外部服务。
- 优先识别数字及小数点，减少房间名称等无关文字干扰。
- 先对尺寸标注常见的建筑外围区域识别；必要时才扩大范围。
- OCR 结果和采用的尺寸证据写入 `recognition.json`，便于复核。

### 安全边界

- 不使用 OCR 数字直接推算比例尺，必须有匹配的矢量尺寸线和两个端点证据。
- 不用图签比例、房间编号、轴号或面积数字替代总尺寸。
- 不改变已经验证成功的房间闭合、唯一候选和单直线补线规则。

## 手动标定画布设计

- 在结果容器显示、原图具有非零显示尺寸后，再同步画布的内部宽高。
- 开始手动标定时再次同步尺寸，防止图片缓存、窗口缩放或隐藏状态造成陈旧尺寸。
- 若画布显示尺寸无效，不接受点击并提示等待图片完成显示。
- 第一点击只显示一个小型黄色端点，第二点击显示另一端点和连接线，不改变原图颜色。

## 测试与验证

- 单元测试：无原生文本时调用 OCR 后备；有原生文本时不调用 OCR。
- 单元测试：OCR 数字必须经现有矢量尺寸线和端点校验，双轴一致才自动确认。
- 回归测试：无可靠候选时仍保持未确认，不产生虚假比例尺。
- 前端测试：显示结果后画布宽高大于 1；第一次点击不会覆盖整图；可连续记录两个点。
- 真实案例：第 13 页应保持 `room_count=17` 和既有补线结果，并自动识别水平、竖直总尺寸，生成已确认比例尺。

## 非目标

- 不尝试把矢量轮廓永久转换成 PDF 原生文字。
- 不改动房间拓扑修复算法。
- 不在本轮审计墙体、窗户面积计算。
