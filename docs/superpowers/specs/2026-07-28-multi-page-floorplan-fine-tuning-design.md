# 多页建筑平面图微调设计

## 目标

把已经确认的一、二、三层标注作为三个训练样本，从原始基础 checkpoint
`models/M2_pub_plus_user.pt` 开始微调一个新模型，并分别报告三层的识别结果。

## 范围

- 训练入口接受标注工具导出的 `fine_tune` 多样本数据集。
- 保留现有 `single_page_overfit` 行为，避免破坏上一轮实验。
- 训练报告使用数据集真实的 `experiment_type`，不得把多页训练伪装成单页过拟合。
- 多页训练仍然没有独立验证集，因此报告必须保持
  `has_independent_validation: false` 和 `generalization_claim: false`。
- 本次训练始终从 `models/M2_pub_plus_user.pt` 加载，不继承一层单页过拟合模型。
- 输出写入新的外部模型目录，不覆盖仓库 checkpoint、网站 ONNX 或现有实验。

## 数据

联合数据集包含 PDF 第 13、14、15 页，共三个已确认样本：

- 第13页：一层；
- 第14页：二层；
- 第15页：三层。

训练前必须通过现有导出数据校验，包括文件存在性、SHA-256、蒙版尺寸、
类别范围和 confirmed 状态检查。

## 训练策略

- 设备：CPU；
- 初始学习率：`5e-5`；
- 最大轮数：20；
- 权重衰减：`1e-4`；
- 每轮数据增强重复次数：2；
- 固定随机种子，保持实验可复现；
- 继续使用现有四分类组合损失和类别权重；
- 继续使用梯度裁剪和最佳平滑训练损失 checkpoint 选择。

该参数比单页实验更保守，用于降低局部墙体膨胀和相邻墙线粘连风险。

## 评估与产物

训练完成后：

1. 对原始基础模型和新模型计算三层汇总的 IoU、Dice 和混淆矩阵；
2. 对第13、14、15页分别计算各类别指标并保存预测蒙版与彩色叠加图；
3. 重点检查一层中上部已发现的粗墙区域是否减轻；
4. 导出 `best.onnx`；
5. 运行 ONNX checker，并比较 PyTorch 与 ONNX Runtime 的数值误差及像素类别一致率。

只有 ONNX 检查通过且逐层结果完成后，才把实验报告为完成。本次不自动替换
网站正式模型；是否接入网站由人工查看三层对比图后决定。

## 错误处理

- 多页数据少于两个样本时拒绝 `fine_tune`；
- 非 confirmed 样本、损坏文件或哈希不一致时训练前失败；
- 非有限损失立即停止，并保留最后一个有效 checkpoint 和日志；
- 输出目录非空时拒绝启动，防止覆盖已有实验；
- ONNX 导出或一致性验证失败时保留 PyTorch checkpoint，但不得报告可部署。

## 测试

- 单元测试证明 `fine_tune` 多样本数据能进入训练；
- 单元测试证明 `single_page_overfit` 仍可训练；
- 单元测试证明不支持的实验类型会被拒绝；
- 单元测试证明多页训练报告保留真实实验类型；
- 运行现有训练数据、损失、实验和 ONNX 导出测试集；
- 最后运行真实三层数据训练、逐层评估和 ONNX 一致性验证。

## 后续阶段

三层联合训练完成后，同一实施计划继续执行“标注区域裁剪”阶段。该阶段允许
整页标注和多个具名裁剪区域并存，详细设计见
`docs/superpowers/specs/2026-07-28-annotation-region-cropping-design.md`。
