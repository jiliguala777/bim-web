# 大矩形补线逐边模型支持率设计

日期：2026-07-29

## 背景

文化宫一层使用一至四层联合微调模型识别后，原始模型蒙版的整体效果优于旧模型，但拓扑修复阶段在图纸左侧空白区域生成了一个不存在的封闭矩形。

本次识别产物位于：

- `G:\bim-web\uploads\energy\BIM-20260729-2163`

诊断记录表明，错误矩形由 `dominant_span_rectangle` 策略生成，矩形坐标为：

- 左上角：`(390, 1058)`
- 右下角：`(704, 2340)`

四条边的支持率如下：

| 边 | PDF 矢量支持率 | 模型支持率 |
|---|---:|---:|
| 上 | 96.83% | 100.00% |
| 下 | 88.89% | 8.25% |
| 左 | 90.65% | 2.10% |
| 右 | 98.36% | 100.00% |

当前实现要求每条边的 PDF 矢量支持率至少为 60%，但模型支持率仅要求至少为 2%。轴网线、尺寸线等非墙体矢量线因此能够提供很高的矢量支持，使模型几乎不支持的边仍被接受。

## 目标

让 `dominant_span_rectangle` 只在矩形四条边分别获得足够模型证据时才允许补线，阻止单条或多条低支持边借助其他高支持边的平均值通过。

本次调整采用保守策略：不在缺少模型证据时生成大面积封闭区域；如果原始模型蒙版本身已经包含可信的大面积封闭区域，则跳过外墙补线，不应错误退回人工处理。

## 范围

本次调整两个紧密相关的拓扑判断：

- `dominant_span_rectangle` 大矩形补线的逐边支持率门槛；
- 外墙补线前的 `already_closed` 判定。

不调整：

- 模型推理和后处理；
- 短缺口 `multi_gap_solution`；
- 小型 U 形内部构件修复；
- PDF 建筑区域检测；
- 已有房间面积计算公式；
- 模型文件和训练数据。

## 规则设计

在 `_dominant_span_rectangles` 中继续分别计算上、下、左、右四条边的：

- PDF 矢量支持率；
- 模型障碍物支持率。

候选矩形必须同时满足：

1. 四条边各自的 PDF 矢量支持率均不低于 `0.60`；
2. 四条边各自的模型支持率均不低于 `0.15`；
3. 现有面积、长宽比、外部泄漏区域、房间保持和合理性检查继续通过。

判断使用每条边的最小值，不使用四边平均值代替逐边门槛：

```text
min(vector_side_supports) >= 0.60
min(model_side_supports) >= 0.15
```

文化宫一层错误矩形的左边为 `0.021`、下边为 `0.0825`，因此会在候选生成阶段被拒绝。

## 原始蒙版已闭合判定

在搜索任何外墙补线候选前，先用 `max_gap_px=0` 提取原始模型蒙版中的房间拓扑。

定义：

- `roi_area`：建筑 ROI 面积；
- `initial_total_closed_area`：原始蒙版全部有效封闭房间面积之和；
- `initial_largest_room_area`：原始蒙版最大封闭房间面积。

只有同时满足以下两个条件，才判定原始蒙版已经可靠闭合：

```text
initial_total_closed_area >= roi_area * 0.20
initial_largest_room_area >= roi_area * 0.08
```

双门槛避免以下两类误判：

- 只有一个小房间闭合、主体仍开放时，总面积不足 20%，不能短路；
- 大量小型文字或图例碎片偶然闭合时，最大单区不足 8%，不能短路。

命中该条件后：

- 跳过 `dominant_span_rectangle` 和 `multi_gap_solution` 外墙搜索；
- `exterior_repair.status = "not_needed"`；
- `exterior_repair.reason = "already_closed"`；
- `closure_status = "complete"`；
- `manual_exterior_wall_required = false`；
- 不增加任何外墙线；
- 仍保留后续内部小碎片的保守处理。

文化宫一层原始蒙版的总封闭面积约占 ROI 的 42.7%，最大房间约占 ROI 的 32.9%，因此应命中 `already_closed`，同时避免进入耗时约 177 秒的多缺口搜索。

## 诊断信息

为便于后续校准，候选和已接受的 `dominant_span_rectangle` 诊断记录增加逐边数值：

```json
{
  "vector_support_by_side": {
    "top": 0.9683,
    "bottom": 0.8889,
    "left": 0.9065,
    "right": 0.9836
  },
  "model_support_by_side": {
    "top": 1.0,
    "bottom": 0.0825,
    "left": 0.021,
    "right": 1.0
  }
}
```

保留现有平均支持率字段，避免破坏已有识别报告和调用方。

## 失败处理

当原始蒙版未达到 `already_closed` 双门槛，且任意一条候选边低于模型支持率门槛时：

- 不生成该矩形的四条补线；
- 继续尝试现有短缺口补线策略；
- 如果没有其他可靠方案，沿用现有的人工外墙处理标记；
- 不修改原始模型蒙版。

当原始蒙版达到 `already_closed` 双门槛时，不进入补线失败流程。后续 `load_geometry_ready` 仍由已有房间拓扑和比例尺状态决定，不再因为“本轮补线新增面积为 0”被强制关闭。

## 测试设计

### 回归测试：拒绝文化宫左侧假矩形

构造或从本次产物提取一个最小化测试输入，使候选四边模型支持率与本次误判具有相同特征：

- 两条边高支持；
- 一条边约 8% 支持；
- 一条边约 2% 支持；
- 四条边均有高 PDF 矢量支持。

预期：

- `dominant_span_rectangle` 不被接受；
- 输出蒙版中不出现该矩形新增线；
- 诊断结果不将该候选标记为已修复。

### 正常案例：允许四边均达标

构造四条边模型支持率均不低于 15%、矢量支持率均不低于 60% 的候选。

预期：

- 现有大矩形补线仍可接受该候选；
- 房间保持和面积合理性检查继续生效。

### 边界测试

- 模型支持率恰好为 15% 时允许继续评估；
- 任意一边略低于 15% 时拒绝；
- 矢量支持率不足时仍按原规则拒绝；
- 短缺口和内部 U 形补线测试保持通过。

### 已闭合短路测试

构造一个原始蒙版，其中：

- 总封闭面积不低于 ROI 的 20%；
- 最大房间面积不低于 ROI 的 8%；
- 矢量支持蒙版中包含可能诱发错误补线的额外长线。

预期：

- `exterior_repair.reason = "already_closed"`；
- 不接受任何外墙补线；
- `closure_status = "complete"`；
- `manual_exterior_wall_required = false`。

### 小房间不应短路

保留现有“只有小房间闭合、主体仍开放”案例。

预期：

- 总封闭面积不足 ROI 的 20%；
- 不返回 `already_closed`；
- 继续按现有规则尝试补线或要求人工处理。

## 验收标准

1. 本次文化宫一层输入不再生成左侧假矩形。
2. 原始模型蒙版中的真实识别结果不因本次规则被删除。
3. 满足逐边 15% 门槛的正常大矩形候选仍可补线。
4. 文化宫一层原始大房间被识别为 `already_closed`，不进入多缺口搜索。
5. 只有小房间闭合、主体仍开放的案例继续要求修复或人工处理。
6. 现有拓扑修复、房间提取和能耗平台测试全部通过。
7. 识别报告保留原平均支持率，并新增逐边支持率诊断信息。
