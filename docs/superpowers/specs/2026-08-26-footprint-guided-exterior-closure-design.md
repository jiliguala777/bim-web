# 模型区域约束下的外轮廓推断闭合设计

日期：2026-08-26

## 背景

现有 PDF 融合流程已经能够结合模型墙体概率、PDF 原生直线、窗证据和外门弧恢复大部分外墙。但外轮廓拓扑仍只允许两类连接：确认门窗对应的精确缺口，以及不超过约 32 像素的共线小缺口。

真实验证图中，左侧虽然缺少部分墙线，但现有墙段仍可能提供替代闭合路径；右上角同时缺少水平外墙和竖向外墙，形成约 124 像素与 152 像素的直角断点。只补右上角后，其他外墙带上的长空档仍会使图结构无法产生任何闭合面，因此不能计算外轮廓面积和周长。

模型的建筑区域概率在该图上能够形成稳定的主要建筑区域，但原始概率轮廓存在锯齿、局部鼓包和标注干扰，不能直接替代墙线计算面积。

## 目标

- 保留现有墙体、窗、外门弧和门弧墙段恢复流程。
- 仅在现有拓扑无法闭合时，生成最少量的水平或竖直推断边。
- 使用已有外墙作为几何锚点，使用模型建筑区域概率验证推断边的内外方向。
- 支持同一直线长缺口和由两条边组成的直角拐角缺口。
- 生成一个无自交、可追踪且需要人工确认的主要外轮廓。
- 人工确认后才允许外轮廓面积和周长进入能耗计算。

## 非目标

- 不改变模型训练、权重或推理输入。
- 不把模型概率轮廓直接当作最终建筑边界。
- 不对内部房间、内墙、内门或内窗执行推断闭合。
- 不把推断边自动分类为真实墙、门或窗。
- 不在已有拓扑能够闭合时改变其结果。
- 不由 Codex 执行最终真实图纸验收；用户在平台自行验证。

## 方案选择

采用“墙线锚点 + 模型区域约束 + 最小代价闭合”的混合方案。

不采用以下方案：

- 直接正交化模型区域轮廓：容易把概率图的锯齿和鼓包带入面积。
- 使用建筑外接矩形或简单阶梯包络：可能填平真实凹口并高估面积。
- 全局放宽共线缺口长度：容易把尺寸线、轴线或不相关墙带连接成外轮廓。

## 组件设计

### 1. 触发条件

推断闭合只能作为后备阶段执行。满足以下任一条件时不得运行：

- 现有拓扑已经产生可复核的闭合外轮廓；
- 没有足够的已确认外墙锚点；
- 模型建筑区域概率不可用或尺寸不匹配；
- 建筑 ROI 无效。

### 2. 外墙锚点与悬空端点

锚点仅来自现有外墙集合，包括原始确认外墙、保守连续性恢复墙段以及门弧确认恢复墙段。每个锚点保留候选 ID、方向、内侧方向、原始起终点和证据来源。

首先合并同方向、同内侧方向且位于同一窄墙带上的重叠墙段，再提取没有连接到垂直墙段或相邻共线墙段的端点。平行的双墙线必须保留为不同墙带，不能在候选生成前无条件合并。

### 3. 补边候选

候选只允许严格水平或严格竖直：

- **共线候选**：连接同一墙带上的两个悬空端点。
- **直角候选**：将一条水平墙带和一条竖直墙带延伸到它们的理论交点，形成一段或两段直角连接。

候选两端必须落在已有外墙锚点或其合理延长线上。直角交点必须位于建筑 ROI 内，且不能越过另一个更近、更可信的外墙带。

默认无标尺约束为：

- 单条推断边长度不超过分析图短边的 10%；
- 所有推断边总长度不超过候选外轮廓周长的 12%。

有已确认比例尺时，可以附加实际长度诊断，但本阶段仍以图像比例约束作为统一准入规则。

### 4. 模型区域证据

沿每条候选边在其声明的建筑内侧和外侧分别采样模型建筑区域概率。候选必须满足：

- 内侧采样连续，且平均建筑概率达到现有外墙准入量级；
- 内侧平均概率明显高于外侧；
- 候选边中心附近具有足够的边界支持；
- 候选线段大部分位于建筑 ROI 内；
- 候选不会穿过高概率建筑内部形成捷径。

直角候选的两条边必须分别通过验证，不能用其中一条的强证据替代另一条。

### 5. 最小代价闭合搜索

在“真实外墙边 + 已接受门窗桥 + 现有小缺口桥 + 推断候选边”构成的正交图中枚举闭合面。只接受同时满足以下条件的方案：

- 产生单一主要外轮廓；
- 多边形无自交、无零长度边，且完全位于 ROI 内；
- 多边形内部获得模型建筑区域支持；
- 不出现两个面积接近的竞争外轮廓；
- 推断边长度和占比不超过安全限制。

候选方案按以下优先级选择：

1. 推断边总长度更短；
2. 推断边数量更少；
3. 内外侧概率差更大；
4. 使用真实墙段比例更高；
5. 稳定的坐标顺序，用于保证结果可复现。

若两个方案代价接近且拓扑不同，保持 `exterior_not_closed`，不得静默选择。

### 6. 结果状态与能耗边界

成功推断闭合后，拓扑状态仍为 `review_required`，并设置 `closure_method` 为 `footprint_guided_inference`。系统可以显示面积和周长预览，但 `load_geometry_ready` 保持 `false`。

用户确认后，后端重新校验多边形、自交、面积、周长、推断边比例和来源哈希。校验通过后才允许该外轮廓进入能耗计算。

推断边不进入门窗面积扣除：

- 确认外门和外窗仍按现有宽度及后续页面设置的高度计算面积；
- 推断边只承担外轮廓闭合职责；
- 推断边覆盖的区域不会自动生成门或窗记录。

## 数据产物

外轮廓拓扑增加：

- `closure_method`：闭合来源；
- `inferred_edges`：本次采用的推断边；
- `inference_candidates`：通过基本几何检查的候选及最终判定；
- `inferred_length_px`：推断总长度；
- `inferred_perimeter_ratio`：推断长度占周长比例；
- `inference_reason_codes`：成功或拒绝原因。

每条 `inferred_edge` 至少包含：

- 唯一 ID；
- 起点、终点、方向和长度；
- 连接的锚点墙段 ID；
- 共线或直角推断类型；
- 内侧、外侧与边界概率统计；
- 是否参与最终多边形；
- 原因码。

失败结果也必须保存候选和拒绝原因，便于调参和复核。

## 平台显示

- 绿色：确认外墙和已有门弧恢复墙段；
- 蓝色：确认外门；
- 青色：确认外窗；
- 橙色虚线：最终采用的推断外轮廓边；
- 淡橙色：未采用但可复核的推断候选；
- 红色：仍未解决的缺口。

平台摘要增加推断边数量、推断总长度、周长占比和闭合方法。综合识别图与相关 JSON 继续保存到平台任务的 `vector_pdf_fusion` 文件夹中。

## 失败与安全处理

- 模型内外侧证据不足时拒绝候选。
- 单段或总推断长度超过限制时拒绝闭合。
- 候选穿越建筑内部、产生自交或填平明显凹口时拒绝闭合。
- 存在多个相近闭合方案时保持未闭合。
- 只有模型概率而没有足够墙体锚点时不得生成外轮廓。
- 所有推断结果必须可回溯到输入墙段、概率文件哈希和算法原因码。
- 用户确认接口继续使用服务端重新计算的可信几何，不接受前端直接提交伪造面积或多边形指标。

## 测试与验收

自动化测试覆盖：

- 已有闭合外轮廓不触发推断；
- 具有内外侧证据的共线长缺口能够生成候选并闭合；
- 右上角类型的双段直角缺口能够生成最小直角补边；
- 左侧已有替代闭合路径时不会额外添加推断边；
- 凹形建筑保留真实凹口，不退化为外接矩形；
- 模型证据不足、内外方向相反或穿越建筑内部时拒绝补线；
- 单段超过短边 10% 或总推断长度超过周长 12% 时拒绝；
- 自交和多个竞争外轮廓保持未闭合；
- 推断闭合只生成预览，未经确认不能用于能耗计算；
- 确认接口重新校验推断边和多边形指标；
- 门窗宽度和面积扣除不包含推断边；
- 现有墙体、窗、门弧恢复、小缺口闭合和能耗测试不回归。

完成代码与自动化回归后，由用户在能耗平台使用真实图纸执行最终视觉验收。
