## 四、原始工具与当前网站的预处理差异

标注工具 `preannotate.py` 使用的预处理流程是：

1. OpenCV BGR 转 RGB。
2. 保持长宽比，将长边缩放到 512 像素。
3. 居中放入 512×512 的黑色画布（letterbox）。
4. 像素除以 255。
5. 使用 ImageNet mean/std 标准化。
6. 模型推理后裁掉填充区域。
7. 使用最近邻插值将类别 mask 恢复到原图大小。

当前网站 `floorplan_onnx.py` 的流程不同：

1. 清除彩色标注。
2. `preprocess_dark_cad()` 将白底 CAD 图转成黑底增强图。
3. 不保持长宽比，直接拉伸到 512×512。
4. 使用 ImageNet mean/std 标准化。

文化宫四层截图是白底图。当前网站会先反色，而训练工具的原始流程没有这一步。即使 ONNX 导出正确，预处理差异也可能导致识别效果明显不同，所以必须实际对比两组结果。

- 最大绝对误差。

只有数值一致性通过，才能说明导出本身可靠。

## 七、PyTorch DLL 问题的处理结果

此前 Anaconda 基础环境中的 `torch 2.9.1` 在 Windows 上导入时出现 `WinError 1114`，失败位置为 `c10.dll` 初始化。

排查结论：

- 不是 `.pt` 模型文件损坏导致的。
- 不是误装 CUDA 版本导致的，当时也是 CPU 包。
- 不符合常见 Intel OpenMP 重复加载冲突的表现。
- 与 PyTorch 2.9.x 在部分 Windows 机器上的 DLL 初始化回归相符。

已将基础环境改为：

```text
torch 2.5.1+cpu
sympy 1.13.1
```

- `import torch` 正常。
- 基本张量运算正常。

- 项目 34 项测试通过。
